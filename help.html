버전 업그레이드 소식

• 구글 지도 API 키 복원: 해외 구글 지도 모드가 정상 작동하도록 API 키 시스템을 완벽히 복원했습니다.

• 긴 일정·주소 전체 노출: 타임라인에서 긴 장소명이나 주소가 말줄임표로 잘리지 않고 자동으로 줄바꿈되어 전부 표시됩니다.

• 날짜 및 요일 자동 계산: 각 일차 타이틀 옆에 실제 날짜와 요일(예: 2026.10.23 금요일)이 자동으로 계산되어 표시됩니다.

• 가계부 카테고리 확장: 기존 숙박, 장보기에 더해 쇼핑, 교통비, 통신,보험 카테고리가 추가되어 세부 지출 관리가 가능합니다.

• 홈 화면 아이콘 및 링크 썸네일 지원: 스마트폰 바탕화면 바로가기 앱 아이콘 및 카카오톡 링크 공유 시 대표 썸네일이 예쁘게 표시됩니다.

• 듀얼 지도 시스템: 국내(카카오맵)와 해외(구글맵)를 자유롭게 전환하는 타임라인 계획·방문 동선 지도.

• 대분류 폴더 구조: 연도별 여행 일정(대분류 1) 및 국내/해외 지역별 소분류 폴더(대분류 2) 시스템 도입.

• 네이버 길찾기 연동: 장소와 장소 사이 이동 거리·소요시간 박스 터치 시 네이버 지도 자동차 길찾기 즉시 실행.

• 1/N 가계부 정산: 실시간 예산 비교 및 1인당 회비(100원 단위 올림 계산) 산출 및 카카오톡 공유 기능.

• 5대 분류 체크리스트 및 차량 배치: 준비물, 먹거리, 현장 구입품목(가계부 연동), 예약사항 및 차량 탑승 명단 관리.

• 통합 엑셀 백업 및 복원: 모든 여행 데이터를 엑셀(.xlsx) 파일로 백업하고 1초 만에 고속 복원.

화면 페이지별 상세 이용 가이드

• 대분류 1 (연도별): 출발일 연도(`2026년` 등)별로 폴더가 자동 생성되어 과거와 현재의 여행을 모아 볼 수 있습니다.

• 대분류 2 (지역별): 국내 6대 권역 및 해외 8대 권역 소분류 폴더를 통해 원하는 지역의 여행을 쉽게 찾을 수 있습니다.

• 엑셀 백업·복원: [폰 저장/공유]나 [PC 다운로드]로 전체 데이터를 파일화하고, [엑셀 복원]으로 안전하게 되돌릴 수 있습니다.

• 날짜 및 요일 표시: 각 일차 타이틀 옆에 실제 날짜와 요일이 자동 계산되어 일정 조율이 편리합니다.

• 구간 이동 정보 박스: 장소와 장소 사이 파란색 박스를 누르면 출발지·목적지가 자동 입력된 네이버 지도(국내) 또는 구글맵(해외) 길찾기가 열립니다.

• 방문완료 연동: [방문전] 버튼을 누르면 [방문완료]로 바뀌며 지도 실선이 강조되고 가계부 지출로 자동 기록됩니다.

• 대안 장소 1초 교체: 등록된 대안 후보 장소가 있다면 [🔄 대안 교체]를 눌러 메인 일정과 즉시 맞바꿀 수 있습니다.

• 장소명 검색: 상호나 키워드를 검색하면 주소, 전화번호, 위도·경도가 자동으로 채워집니다.

• 지도 직접 터치: 지도를 직접 터치하면 해당 위치의 위도·경도와 도로명 주소가 자동 입력됩니다.

• 대안 후보 추가: 예상 일정 추가 시 비상용 대안 장소(식당 등)를 미리 등록해 둘 수 있습니다.

• 카테고리 세분화: 식당, 카페, 관광, 숙박, 장보기뿐만 아니라 쇼핑, 교통비, 통신,보험 항목으로 지출을 관리합니다.

• 1/N 정산 계산기: 정산 인원 변경 시 1인당 정확한 회비와 100원 단위 올림 회비가 실시간 계산됩니다.

• 카카오톡 공유: [카카오톡 공유용 가계부 정산 내역 복사하기]를 눌러 단톡방에 즉시 공유할 수 있습니다.

• 차량 배치 연동: 등록된 운전자와 동승자 이름이 체크리스트 담당자 및 가계부 결제자 목록에 자동으로 연동됩니다.

• 현장 구입품목 가계부 연동: '4. 여행중 현장 구입품목'에서 금액을 입력하고 [가계부반영]을 누르면 가계부 지출로 즉시 등록됩니다.

• 미완료 복사: 체크되지 않은 준비물만 골라 단톡방에 복사하여 공유할 수 있습니다.

• 읽기 전용 잠금: 상단 [🔓 편집중] 버튼을 눌러 [🔒 잠금됨]으로 전환하면, 일행들이 스마트폰으로 일정을 볼 때 실수로 내용을 지우거나 수정하는 사고를 원천 차단할 수 있습니다.
